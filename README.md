## Столичная одежда
Проект направлен на создание информационного сайта, посвященного одежде столичных жителей из низших социальных слоев с периода Древней Руси до начала XX века. Основной результат проекта - цифровой ресурс, позволяющий просматривать и изучать повседневную одежду по историческим эпохам.

Финальной задачей для нас было довести проект до конца, исправить все проблемы с  сайтом и сделать интерактивную часть.

В прошлом варианте работы были проблемы с некоторыми источниками, так как сайты rusarch и iriran сменили свои домены, а также, поработав с текстом, мы определили какие источники мы не использовали в итоге и удалили их с сайта и файла отчета.

На главную страницу был добавлен блок с интерактивной частью. Здесь можно выбрать социальную группу и прочитать, какую одежду носили эти люди и почему.

С точки зрения кода была добавлена система ci/cd для упрощения работы с обновлениями и загрузки кода.

Код проекта - https://github.com/Votemha/history-social-project-metropolitan-clothing Последняя сборка находится в файле docs, с нее же и работает сайт.  

Сайт - https://votemha.github.io/history-social-project-metropolitan-clothing/ На сайте сделано основное оформление, кодовая база, общая информация.
